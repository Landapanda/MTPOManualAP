# Mike Tyson's Punch-Out!! Manual Archipelago 

## Checks
- **TKOs:** TKO any available opponent
- **KOs:** KO any available opponent, if they are able to be KO'd
- **Decisions:** Defeat your opponent via decision, if they are able to be defeated by decision.

## Items
- Fighters: Starting with Glass Joe, you unlock each fighter individually.
- Pass Codes: Unlock all pass codes, allowing you to access fights previously inaccessible or just to save time from playing through circuits again.
- Rounds: Start with only one round and unlock increments to let you get KOs and Decisions.
- Stars: Start without the ability to use any stars and unlock increments to use all 3.
- Healing: Unlock the ability to heal in between rounds.

## Goals
- **TKO Mike Tyson**
- **KO Mike Tyson**
- **Mike Tyson Decision**

## Options

Select your goal from the three goals listed above.
